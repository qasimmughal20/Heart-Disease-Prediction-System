📋 Overview

CardioScan AI is a comprehensive, end-to-end machine learning system for predicting heart disease risk. It analyzes 13 medical parameters to provide instant risk assessment with 85%+ accuracy. The system offers three interfaces (Web App, Desktop Application, and REST API) making it accessible for healthcare providers, researchers, and individuals seeking quick health risk assessments.



🎯 Key Features

AI-Powered Prediction: Logistic Regression model trained on real patient data

Multiple Access Points: Web interface (Streamlit), Desktop app (Tkinter), REST API (Flask)

Risk Categorization: High/Medium/Low risk levels with probability scores

Personalized Recommendations: Health advice based on specific risk factors

PDF Reports: Professional medical reports with patient data

Patient History: Track all predictions with search and export functionality

Admin Dashboard: Model performance metrics and dataset analytics

Demo Samples: One-click loading of example patients for testing



🏥 Problem Statement

Cardiovascular diseases are the leading cause of death globally, responsible for approximately 17.9 million deaths annually. Early detection and risk assessment are crucial for prevention and treatment. However, traditional risk assessment methods are often time-consuming and require specialist consultations.



CardioScan AI addresses this by providing:

Quick Screening: Instant risk assessment using 13 medical parameters

Accessibility: Multiple interfaces for different user needs

Cost-Effective: Free, open-source solution for healthcare providers

Educational: Helps patients understand their risk factors
